# TestZeus logos

Hercules is an open-source QA engine by [TestZeus](https://testzeus.com). These are the official TestZeus logos.

| File | Use it on |
|---|---|
| `testzeus-logo-on-light.png` | Light backgrounds (navy letters, blue bolt) |
| `testzeus-logo-on-dark.png` | Dark backgrounds (white letters, blue bolt) |
| `testzeus-logo-black.png` | One-colour print or light backgrounds |
| `testzeus-logo-white.png` | One-colour use on dark backgrounds |
| `testzeus-monogram-on-light.png` | Small spaces on light backgrounds: icons, avatars |
| `testzeus-monogram-on-dark.png` | Small spaces on dark backgrounds |
| `testzeus-monogram-black.png`, `testzeus-monogram-white.png` | One-colour versions of the monogram |

Brand colours: navy `#002030`, bolt blue `#0FA2FF`.

Use them to refer to TestZeus or Hercules, and keep them as they are: no recolouring, stretching or effects.
